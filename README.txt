DEPLOY FOR FREE WITH GITHUB PAGES
1. Sign into GitHub on your phone or PC.
2. Create a new PUBLIC repository named paxton-training-lab. (A public GitHub Pages site is accessible to anyone with its URL; don't put private data into it.)
3. Upload ALL SEVEN files from this folder into the repository root.
4. Open repository Settings > Pages. Choose Deploy from a branch, main, /(root), Save.
5. Wait for GitHub Pages to publish; open the displayed HTTPS link in Android Chrome.
6. Chrome menu (three dots) > Install app or Add to Home screen.
7. Open the installed app once while online; after the service worker has cached its files it works offline.

Use Load circuit to get started. Add wire: tap two terminals. Remove wire: select Remove wire and tap a line, or use the list. Red/Black probe: select then tap terminals. The reader release lasts three seconds. RTE is press-and-hold; fire and break glass latch until reset. Wiring is saved on the device.

NOTE: This is an educational approximation, not an approved wiring schematic. Fire release and egress safety must be designed and tested to applicable standards and product instructions.
